# Shiro companion art

The portrait and expression crops here were extracted locally from the user-provided `Shiro CodeMind Neon Asset Sheet.png`. The UI maps static expressions to actual request states and uses CSS transitions; these files are not rigged animation or project-generated art.

`shiro-icon-32.png` and `shiro-icon-180.png` are resized from the neutral Shiro expression for the browser favicon, app icon, and workspace brand mark.
